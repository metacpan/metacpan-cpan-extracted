# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in Smart::Options, do not open a public issue. Report it through GitHub's [Private vulnerability reporting](https://github.com/kan/p5-smart-options/security/advisories/new) instead. Only the maintainer can see the report until a fix is published.

Please include:

- What the vulnerability is
- Steps to reproduce it (the command line arguments or the config file that trigger it, if any)
- The expected impact

Reports are checked and answered as soon as possible.

## Scope

In scope are the code in this repository and the [Smart-Options](https://metacpan.org/dist/Smart-Options) distribution on CPAN. Fixes are released only for the latest version.

Please report these elsewhere:

- Vulnerabilities in other dependencies: the project that publishes the dependency
