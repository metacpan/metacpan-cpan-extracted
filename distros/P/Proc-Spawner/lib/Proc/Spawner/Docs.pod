=head1 NAME

Proc::Spawner::Docs - a map of the design documents shipped in F<doc/> (EXPERIMENTAL)

=head1 DESCRIPTION

Besides the POD of its modules, the distribution ships its design notes as Markdown files under F<doc/>.
CPAN tools do not show those files as documentation, so this page lists them, says who wrote them and
what each is for, and links to each one twice on MetaCPAN:

=over 4

=item *

its name links to the file, rendered, in the newest release;

=item *

"The same file in this release" (shown only in HTML) links to the file in the release whose page you are
reading. This link works from MetaCPAN's pages under F</release/.../view/> and F</dist/.../view/>, not from
F</pod/...>.

=back

The notes were written with Claude. At first two working sessions wrote them, each with its own file prefix:
the I<executor session> (prefix C<pspawn->: L<Proc::Spawner>, L<Proc::Spawner::Graph>, L<Proc::ShellSpawn>)
and the I<parser session> (prefix C<large-subset->: L<Proc::ShellSubset::Large>). Since 2026-11-02 one
session has maintained them all. The base parser's notes (F<doc/parsers/>) come from an earlier session.

Each entry below ends with its B<status>: I<current> (it describes the code of this release) or
I<reference> (a rule set or a procedure that stays valid). I<Older names> means that the document uses the
module names of its day: C<ShellSpawn> is now L<Proc::ShellSpawn>, C<ShellSubsetLarge> is now
L<Proc::ShellSubset::Large>, and so on.

=head2 Historical documents

The working documents of only historical interest (the investigation that started the large parser, the first
corpus statistics, the ceiling measurements, the reports between the sessions, the marks, why Run was replaced) are
in the Proc-Spawner 0.03 distribution on CPAN; this one no longer ships them.

=head2 Which version a result belongs to

Every measured result in these documents names, by a label, the code it was measured on: a release, such
as I<0.03>; I<pre-0.01>, the modules under their former names, before the first distribution; or
I<post-N>, release N plus later work, not released. The table at the end of F<doc/README.md> lists every
label.
