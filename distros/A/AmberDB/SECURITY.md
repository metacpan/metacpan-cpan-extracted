# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| < 5.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within AmberDB, please do **NOT** open a public issue on GitHub.

Instead, please send an email directly to **Maruf Cetin** at:

`marufcetin@gmail.com`

Please include:
- A description of the vulnerability.
- Steps or a minimal Perl script to reproduce the issue.
- Potential impact and recommended mitigation if known.

You should receive an acknowledgment within 48 hours. Valid vulnerabilities will be addressed in a patch release as quickly as possible.
