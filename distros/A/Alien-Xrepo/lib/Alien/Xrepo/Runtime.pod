=head1 NAME

Alien::Xrepo::Runtime - Consumer class for xrepo-based Aliens

=head1 SYNOPSIS

    package Alien::Zstd;
    use v5.40;
    use experimental 'class';
    use Alien::Xrepo::Runtime;

    class Alien::Zstd : isa(Alien::Xrepo::Runtime) {
        method pkg_name {
            return [ { name => 'zstd', kind => 'shared' } ];
        }
    }

    1;

=head1 DESCRIPTION

C<Alien::Xrepo::Runtime> is the post-build accessor layer for an xrepo-based Alien. It deliberately avoids the
L<Alien::Base> model of generating a per-subclass C<::ConfigData> module at build time: package paths are resolved by
asking xrepo itself -- lazily, once per package, cached for the process -- so a fresh checkout of an Alien using this
class works with no build step at all.

Optionally a C<xrepo.json> recipe instead of an inline C<pkg_name>, and a snapshot written by L<Alien::Xrepo::Build>
(auto-detected from the dist share dir, see C<autodetect_snapshot>) makes resolution fully hermetic: the accessors then
serve recorded paths and never spawn xrepo.

=head1 METHODS

The accessor surface follows the L<Alien::Base> conventions. Each accessor takes an optional package name and defaults
to the primary (first declared) package.

=over

=item C<cflags( [$pkg] )>

Include flags (C<-I...>) for the package. Returns an empty string when the package cannot be resolved.

=item C<cflags_static( [$pkg] )>

Include flags for static linking. An alias of C<cflags( )> in this release.

=item C<libs( [$pkg] )>

Link flags (C<-L... -l...>) for the package. Returns an empty string when the package cannot be resolved.

=item C<libs_static( [$pkg] )>

Link flags for static linking. An alias of C<libs( )> in this release.

=item C<libpath( [$pkg] )>

Absolute path to the package's runtime library (DLL/SO/dylib). C<undef> for a header-only package or when
resolution failed.

=item C<ffi_lib( [$pkg] )>

An alias of C<libpath( )> under the name L<Alien::Base> C<build_ffi> consumers call.

=item C<dynamic_libs( [$pkg] )>

Absolute paths to every library file xrepo reported for the package.

=item C<bin_dir( [$pkg] )>

Executable directories (a tool package's C<bin>). An empty list when the package has none.

=item C<version( [$pkg] )>

The installed version as reported by xrepo, or C<undef> before resolution.

=item C<kind( [$pkg] )>

The package kind -- C<library> for libraries, C<binary> for tools -- as reported by xrepo.

=item C<dist_dir( [$pkg] )>

The package's install root (where its files live), or C<undef> before resolution.

=item C<install_type( [$pkg] )>

C<'share'> once the package has resolved, C<'system'> otherwise. In hermetic snapshot mode the value recorded
in the snapshot is returned unchanged.

=item C<alt( $name )>

An accessor bound to a non-primary package; C<alt> of the primary returns C<$self>. E.g. C<<
Alien::SDL3->alt('libsdl3_ttf')->cflags >>.

=item C<find_header( $file, [$pkg] )>

Absolute path to a header within the package include directories, or C<undef> if it is not found.

=item C<package_info( [$pkg] )>

The underlying L<Alien::Xrepo::PackageInfo>, or C<undef> before resolution.

=item C<package_names()>

The recipe's package names in declaration order (first is the primary package).

=item C<package_defs()>

The recipe's normalized per-package definition hashref.

=item C<split_flags( $flags, [$pkg] )>

Splits a flag string on whitespace and returns the individual flags (Windows-safe list form). The package
argument is accepted for compatibility with the other accessors but the split itself does not use it.

=back

=head1 CONSTRUCTOR

    Alien::Zstd->new(
        pkg_name     => 'zstd',                  # or an arrayref of names / hashref defs
        recipe       => $path_or_recipe,         # alternative to inline pkg_name
        install_opts => { kind => 'shared' },    # ambient flags under every package
        root         => $store_root,
        repo         => $alien_xrepo,            # injectable engine
        cache        => 0,                       # bypass Alien::Xrepo's warm-start cache
        snapshot     => $file,                   # hermetic data; wins over dynamic fetch
        autodetect_snapshot => 1,                # look in the installed dist share dir
        verbose      => 1,
    )

Subclasses may also declare C<pkg_name> and C<install_opts> as methods, which the constructor honors when no
constructor argument is supplied.

B<cache> (default 1) is forwarded to the engine created by this class, so C<cache =E<gt> 0> disables
L<Alien::Xrepo|/CACHE>'s on-disk resolution cache for a fully live, one-spawn-per-package consumer. When
C<repo =E<gt> ...> injects an engine, that engine's own cache setting is used instead.
