# ShellSpawn and its parser: the record of known issues

This is the single list of known problems of the distribution (the shell layer [`lib/Proc/ShellSpawn.pm`](../lib/Proc/ShellSpawn.pm), the spawner [`lib/Proc/Spawner.pm`](../lib/Proc/Spawner.pm), its Windows part, the measurements) and of the bugs it found elsewhere. Each item keeps its ID when it is fixed; fixed items move to the end. Older records, now summarized here: [`Run's Changes, 0.05 and 0.06`](https://metacpan.org/release/ILYAZ/Run-0.07/changes) (Run R1–R5), [`pspawn-run-shortcomings.md` (0.03)](https://metacpan.org/release/ILYAZ/Proc-Spawner-0.03/view/doc/pspawn-run-shortcomings.md) (in Proc-Spawner 0.03) (Run, summary), [`pspawn-upstream-reports.md` (0.03)](https://metacpan.org/release/ILYAZ/Proc-Spawner-0.03/view/doc/pspawn-upstream-reports.md) (in Proc-Spawner 0.03) (P1).

Module names: since 2026-11-02, 07:30 every module is under `Proc::` (`ShellSpawn` is `Proc::ShellSpawn`, the binding `PosixSpawn` is part of `Proc::Spawner`); rows written before keep the old names. Table: [`pspawn-spawner.md`](pspawn-spawner.md), top.
