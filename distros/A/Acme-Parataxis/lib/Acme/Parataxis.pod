=head1 NAME

Acme::Parataxis - Lightweight Cooperative Fibers

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[:all];
    $|++;
    async {
        say 'Main task started';
        my $f1 = fiber {
            say '  Task 1: Sleeping...';
            await_sleep(1000);
            say '  Task 1: Waking up';
            return 'Coffee!';
        };
        my $f2 = fiber {
            say '  Task 2: Calculating... (simulated CPU work)';
            my $sum = 0;
            for ( 1 .. 100 ) {
                $sum += $_;
                yield;    # yield control back to the scheduler
            }
            say '  Task 2: Complete. Will return ' . $sum;
            return $sum;
        };

        # await works on fibers and futures
        say 'Result 1: ' . await($f1);
        say 'Result 2: ' . await($f2);
    };
    # Output:
    # Main task started
    #   Task 1: Sleeping...
    #   Task 2: Calculating... (simulated CPU work)
    #   Task 2: Complete. Will return 5050
    #   Task 1: Waking up
    # Result 1: Coffee!
    # Result 2: 5050

=head1 DESCRIPTION

C<Acme::Parataxis> brings stackful cooperative multitasking (green threads or fibers) and native thread-pool offloading
to Perl. It combines cooperative multitasking (fibers) with a preemptive native thread pool.

All Perl code runs within a fiber: a user-space thread of execution with its own C-level execution context and
independent Perl interpreter stacks (argument, mark, scope, save, and mortal stacks). Unlike preemptive OS threads,
fibers are cooperatively scheduled: a fiber runs until it yields or pauses for a blocking operation. Because scheduling
is deterministic, mutable state shared across fibers requires no mutex locks unless an operation suspends across a
yield boundary.

When a fiber encounters a blocking task such as sleeping or waiting on a file descriptor, it will not stall the Perl
interpreter. Instead, the calling fiber is suspended, the blocking wait is offloaded to a background OS worker thread
in a native C thread pool (or an attached event loop), and the scheduler resumes other runnable fibers. Once the
background operation completes, the parked fiber is re-enqueued and resumes with its result.

The core exports the scheduler interface (C<async>, C<run>), fiber lifecycle tools (C<fiber>, C<spawn>, C<yield>,
C<await>), async I/O primitives (C<await_sleep>, C<await_read>, C<await_write>), structured concurrency (C<nursery>),
and cooperative cancellation (C<with_timeout>, C<with_cancel>).

Higher-level abstractions are separated into dedicated companion classes:

=over

=item * L<Acme::Parataxis::Actor> - Isolated state behind a private fiber with an incoming mailbox.

=item * L<Acme::Parataxis::Channel> - Bounded CSP message queues with backpressure and multiplexed C<select>.

=item * L<Acme::Parataxis::Blocking> - Offload heavy CPU work to cloned interpreters or forked processes.

=item * L<Acme::Parataxis::Future> - Single-assignment asynchronous values and completion hooks.

=item * L<Acme::Parataxis::Stream> - FRP-style streaming pipelines over bounded channels.

=item * L<Acme::Parataxis::Sync> - Mutexes, read/write locks, wait groups, barriers, and initializers.

=item * L<Acme::Parataxis::TVar> - Software Transactional Memory (STM) with automatic retry on conflict.

=item * L<Acme::Parataxis::Compat> - Gevent-style transparent unblocking for legacy C<sleep> and C<read> calls.

=back

This project was greatly inspired by the concurrency system for the L<Wren|https://wren.io/concurrency.html>
programming language and my own curiosity; I wanted to see how hard it would be to fiddle with perl's core from an FFI
and nothing requires more fiddling than picking up the full context and swapping it around at runtime.

=head1 FUNCTIONS

Importable individually or with the C<:all> tag.

=head2 C<async { ... }>

    async {
        # scheduler starts, executes block as the root fiber, and stops when finished
    };

Convenience wrapper around C<run()>. Executes the provided code block as the initial root fiber of a new scheduler
session and stops the scheduler once the block returns or dies.

=head2 C<fiber { ... }>

    my $f = fiber {
        my $val = do_work();
        return $val;
    };

Creates and schedules a new fiber. An alias for C<spawn()>. Returns the C<Acme::Parataxis> fiber object, which
implements the Future interface (C<await>, C<result>, C<error>, C<on_ready>).

=head2 C<await( $target )>

    my $val = await($fiber_or_future);

Suspends the current fiber until C<$target> completes. C<$target> may be an C<Acme::Parataxis> fiber, an
L<Acme::Parataxis::Future>, or an L<Acme::Parataxis::Monitor>. Returns the resolution value or rethrows the target's
death error in the caller.

=head2 C<yield( [@args] )>

    yield();
    my $reply = yield('hello');

Suspends the current fiber and returns control to the scheduler. If C<@args> are passed, they are delivered to the
context that next calls or resumes this fiber.

=head2 C<await_sleep( $ms )>

    await_sleep(250);    # sleep 250 milliseconds

Cooperatively suspends the current fiber for C<$ms> milliseconds. The delay is handed to the native thread pool or
attached driver, allowing other fibers to execute.

=head2 C<await_read( $fh, [$timeout_ms = 5000] )>

    my $ready = await_read( $socket, 2000 );

Suspends the current fiber until C<$fh> is ready to read or the timeout expires. Returns C<1> on readiness, C<-1> on
timeout or unwatchable handle.

=head2 C<await_write( $fh, [$timeout_ms = 5000] )>

    my $ready = await_write( $socket, 2000 );

Suspends the current fiber until C<$fh> is ready to accept writes. Returns C<1> on readiness, C<-1> on timeout.

=head2 C<with_timeout( $ms, [$token,] $code )>

    my $val = with_timeout( 1000, sub {
        return fetch_data();
    } );

Runs C<$code> under a strict deadline. If execution does not complete within C<$ms> milliseconds, any parked wait
aborts and throws L<Acme::Parataxis::Error::Timeout>. If an optional L<Acme::Parataxis::CancellationToken> is provided,
cancelling the token interrupts the block early with L<Acme::Parataxis::Error::Cancelled>.

=head2 C<with_cancel( sub ($token) { ... } )>

    my ($token, @res) = with_cancel( sub ($t) {
        fiber { await_sleep(100); $t->cancel };
        await_sleep(10_000);
    } );

Executes C<$code> within a scoped cancellation context. The block receives a fresh C<CancellationToken>. Any wait
parked inside the scope is interrupted if the token cancels. In list context, returns the token followed by the block's
return values; in scalar or void context, returns the token alone.

=head2 C<nursery( sub ($n) { ... } )>

    nursery( sub ($n) {
        $n->spawn( sub { worker_one() } );
        $n->spawn( sub { worker_two() } );
    } );

Structured concurrency scope. Runs the block, joins every child fiber spawned through C<< $n->spawn >>, and guarantees
that all children finish before C<nursery()> returns. If any child dies, its siblings are immediately cancelled, the
entire nursery drains, and the primary failure is rethrown as an L<Acme::Parataxis::Error::Nursery>.

=head2 C<wait_all( @futures )>

    my $aggregate = wait_all( $f1, $f2 );
    my $results   = await($aggregate);    # [ $res1, $res2 ]

Takes a list of futures/fibers and returns a new Future that resolves with an arrayref of results once every input has
succeeded. If any input fails, the aggregate fails fast with that first error.

=head2 C<wait_any( @futures )>

    my $winner = await( wait_any( $f1, $f2 ) );

Returns a Future that completes as soon as the first input future settles (whether by success or failure), adopting
that winner's outcome.

=head2 C<pmap( \%opts, $code, @items )>

    my @results = pmap( { concurrency => 4 }, sub ($item) {
        return process_item($item);
    }, @items );

Maps a subroutine over a list of items using a pool of concurrent fibers bounded by C<concurrency> (default: one fiber
per item). Preserves input ordering. If any worker throws, in-flight fibers are cancelled and the error is rethrown.

=head1 SCHEDULER & RUNTIME METHODS

=head2 C<< Acme::Parataxis->run( $code, [%opts] ) >>

    my $status = Acme::Parataxis->run(
        code        => sub { ... },
        virtual     => 0,
        on_shutdown => 1
    );

Starts the scheduler event loop. Options include:

=over

=item * C<virtual =E<gt> 1>

Activates deterministic mock time. Timed waits (C<await_sleep>, timeouts, intervals) do not advance real clocks; time
is stepped explicitly via C<< Acme::Parataxis->advance($ms) >>.

=item * C<on_shutdown =E<gt> 1 | $coderef | $token>

Installs graceful shutdown handlers for C<SIGINT> and C<SIGTERM>. The first signal cancels the run's root token,
unwinding active fibers. Returns exit code C<130> (SIGINT) or C<143> (SIGTERM).

=back

=head2 C<< Acme::Parataxis->stop() >>

Signals the scheduler to exit its loop once currently runnable fibers yield.

=head2 C<< Acme::Parataxis->current_fid() >>

Returns the numeric fiber ID of the currently executing fiber, or C<-1> from top-level unmanaged code.

=head2 C<< Acme::Parataxis->by_id( $fid ) >>

Returns the live C<Acme::Parataxis> fiber object for the given ID, or C<undef> if completed or nonexistent.

=head2 C<< Acme::Parataxis->attach_loop( $loop ) >>

Attaches an external event loop driver (such as C<Mojo::IOLoop> or C<IO::Async::Loop>), delegating descriptor readiness
and timer execution to that loop rather than the native C worker pool.

=head2 C<< Acme::Parataxis->detach_loop() >>

Detaches the current event loop driver and reverts to the built-in native thread pool.

=head1 Behavior Notes

=over

=item * Cooperative execution

A fiber running a tight synchronous CPU loop (e.g. C<1 while 1>) blocks the entire OS thread. Call C<yield>
periodically to let other fibers run, or offload heavy computation with L<Acme::Parataxis::Blocking>.

=item * Stack safety

Each fiber receives an independent C-level and Perl-level stack. C-level stack boundaries are protected by guard pages
allocated via C<mmap>. Exceeding stack limits aborts with a diagnostic error rather than silently corrupting memory.

=item * Exception delivery

When a fiber dies, its exception is retained in its error slot. Awaiting that fiber immediately rethrows the exception
in the awaiting fiber. If an uncaught exception escapes the root fiber of a scheduler run, it propagates out of
C<run()>.

=back
