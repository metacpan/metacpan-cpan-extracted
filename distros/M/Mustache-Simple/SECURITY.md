# Security Policy

## Reporting a Vulnerability
If you discover a security issue in Mustache::Simple, please report it privately.

You can contact the maintainer (DOHNUTS) through:
- CPAN: https://metacpan.org/author/DOHNUTS

Please include:
- a description of the issue
- steps to reproduce (if applicable)
- affected versions
- suggested fixes (optional)

## Supported Versions
Only the latest CPAN release is actively supported.

Older versions may receive fixes depending on severity.

## Disclosure Policy
Please follow the responsible disclosure model:
- report privately first
- allow time for a fix
- public disclosure only after a patched version is released
