=head1 NAME

TUI::Manual::Reference::Porting - Porting Notes

=head1 PORTING NOTES

This document describes the porting of Borland I<Turbo Vision> to Perl.
It focuses on implementation status, class mapping and technical
considerations arising from differences between C++ and Perl.

This document is primarily intended for maintainers and contributors.

The TUI framework is based on the original I<Turbo Vision> 2.0 C++ sources.
The goal of the port is conceptual compatibility rather than a
mechanical translation of code.

Borland's I<Turbo Vision> classes are mapped to Perl modules in a mostly 
one-to-one fashion.

This port is based on the original codebase of Borland C++ 4.02
(Turbo Vision 2.0 sources including bug fixes by Eric Woodruff:
L<tv2fixed.zip|http://www.sigala.it/sergio/tvision/source/tv2fixed.zip>).

The Perl implementation also draws inspiration from I<magiblot>'s
I<A modern port of Turbo Vision 2.0>. Besides using C++ ports of various
assembler routines, the extended color model was adapted from that project and
forms the basis of the enhanced color handling available in the Perl port.

=head2 Class Implementation Status

The following table provides an overview of the implementation status
of major I<Turbo Vision> classes in the Perl port. The status reflects
practical usability rather than theoretical completeness.

 Status legend:
  [ ] Not implemented
  [x] Implemented
  [o] Partially implemented
  [+] Port extension

The status table is intended as a practical guide rather than a strict
feature checklist.

The meanings of the status indicators are as follows:

=over 4

=item [ ] Not implemented

The class does not exist in the Perl port. References to this class are
documented for transparency and orientation only. No compatibility is
provided.

=item [x] Implemented

The class is usable for typical applications. Core functionality is
present and stable. Some optional or rarely used features may still be
missing, but the class can be relied upon in normal use.

=item [o] Partially implemented

The class exists and provides limited functionality. Common use cases
may work, but parts of the API, platform-specific behavior or advanced
features are missing or incomplete. Use with care.

=item [+] Port extension

The class is specific to the Perl port and has no direct equivalent in the
original I<Turbo Vision> implementation. It was introduced to support
additional functionality provided by modern terminals, color handling or
the Perl implementation architecture.

=back

The table focuses on practical relevance. A class marked as implemented
does not imply full parity with the original C++ version in every
detail.
