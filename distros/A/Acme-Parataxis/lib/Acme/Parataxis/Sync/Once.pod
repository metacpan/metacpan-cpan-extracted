=head1 NAME

Acme::Parataxis::Sync::Once - Run an Initialization Action Exactly Once Across Concurrent Fibers

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async fiber];
    use Acme::Parataxis::Sync::Once;

    my $initializer = Acme::Parataxis::Sync::Once->new;
    my $connection;

    async {
        my @workers = map {
            my $id = $_;
            fiber {
                # First fiber executes the block; subsequent fibers park until done:
                $initializer->do( sub {
                    say "Worker $id initializing shared database connection...";
                    $connection = connect_to_db();
                } );

                say "Worker $id proceeding with connection: $connection";
            };
        } 1 .. 4;

        $_->await for @workers;
    };

=head1 DESCRIPTION

C<Acme::Parataxis::Sync::Once> coordinates lazy, one-time initializations across concurrent fibers. The first fiber to
call C<do> executes the provided action; all other concurrent callers park until the action completes and then proceed.

Once the action has completed—whether it returned cleanly, died, or was interrupted—the initializer is marked done.
Subsequent calls to C<do> return immediately without re-executing the action.

=head2 Result Asymmetry

A key design property: B<only the fiber that actually executes the action receives its return value>. Concurrent
waiters and later callers return C<undef>. For this reason, shared initializers should assign their results to an
enclosing lexical variable (as shown in the SYNOPSIS) rather than relying on the return value of C<do()>.

=head1 METHODS

=head2 C<new( )>

    my $once = Acme::Parataxis::Sync::Once->new;

Constructs a new, unexecuted C<Once> instance.

=head2 C<do( sub { ... } )>

    my $res = $once->do( sub { initialize() } );

Executes the code reference if it has never run before:

=over

=item * B<First caller>: Runs the action synchronously on its own fiber. If the action parks (e.g. for I/O or sleep),
the caller parks, and competing fibers queue behind it. Returns the scalar return value of the action.

=item * B<Concurrent callers>: Park until the running action finishes, then return C<undef>.

=item * B<Subsequent callers>: Return C<undef> immediately without parking.

=back

Exceptions:

=over

=item * Croaks if called outside a scheduled fiber.

=item * Croaks if passed an invalid code reference.

=item * Croaks with C<Once::do is not reentrant: this fiber is already running the action> if called recursively from
within the action.

=back

=head2 C<done( )>

    if ( $once->done ) { ... }

Returns true if the action has completed (or failed); false if unexecuted or currently in flight.

=head2 C<waiters( )>

Returns the number of fibers currently parked waiting for the in-flight action to complete.

=head1 Recipes

=head2 Lazy shared resource setup

    my $INIT = Acme::Parataxis::Sync::Once->new;
    my $CONFIG;

    sub get_config () {
        $INIT->do( sub {
            $CONFIG = load_config_from_disk();
        } );
        return $CONFIG;
    }

    # Concurrent callers all receive the initialized $CONFIG safely.

=head2 Bounded initialization wait

Fibers waiting on a C<Once> can be bounded with C<with_timeout>:

    async {
        my $val = eval {
            Acme::Parataxis::with_timeout( 1000, sub {
                $once->do( sub { slow_handshake() } );
            } );
        };
        warn "Timed out waiting for initialization: $@" if $@;
    };

=head1 Behavior Notes

=over

=item * Failed actions mark C<done> permanently

If the action throws an exception or is cancelled mid-execution, the exception is rethrown in the executing fiber, but
C<done> is still set to true. All waiting fibers are unblocked (receiving C<undef>), and future calls will not retry.
This matches the standard behavior of Go's C<sync.Once>. If an initialization is allowed to fail and retry, replace the
C<Once> instance explicitly upon failure.

=item * Re-entrancy spends the Once

Calling C<do()> recursively from within its own action croaks with a re-entrancy error. Because this is an uncaught
exception leaving the action, the C<Once> is finalized as spent, preventing future attempts.

=item * Scalar context execution

The action passed to C<do()> is always evaluated in scalar context. To return multiple values, return an arrayref.

=back
