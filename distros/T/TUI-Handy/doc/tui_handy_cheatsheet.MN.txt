 TUI::Handy Cheat Sheet                                  [MN] Монгол

[ 1. Суулгах ба ачаалах ]

  CPAN хамаарал байхгүй; Handy.pm-ийг @INC доторх дурын хавтас руу хуулах, эсвэл шууд скрипт байдлаар ажиллуулна.

  use TUI::Handy;
  # or, as a command:  perl Handy.pm form.txt

[ 2. Маягт үүсгэх, ажиллуулах ]

  DSL мөр эсвэл файлаас маягт үүсгэж, дараа нь run()-г дуудна; үр дүн нь DSL доторх шошгуудыг түлхүүр болгосон hash лавлагаа юм.

  my $tui  = TUI::Handy->new(dsl => $text);   # or new(file => $path)
  my $form = $tui->run;
  print "Company = $form->{Company}\n";

[ 3. Текст хайрцгийн тэмдэглэгээ ]

  [ ] доторх дүүргэх тэмдэгтүүд текст хайрцгийн төрлийг сонгоно: _ хагас өргөн, # тоо, $ эсвэл \ валют, YYYYMMDD эсвэл % огноо, бүтэн өргөн тэмдэгт бол zenkaku төрөл.

  Company: [__________]
  Age:     [###]
  Price:   [$$$$$$]
  Date:    [YYYYMMDD]

[ 4. Чекбокс ба радио товч ]

  [X]/[ ] нь чекбокс (утга 1 эсвэл 0); (*)/( ) нь өмнөх гарчиг мөрөөр бүлэглэгдсэн радио товч бөгөөд утга нь сонгосон шошгын текст байна.

  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium

[ 5. Товч ]

  Өмнө нь шошгын текст байхгүй дөрвөлжин хаалт нь товч юм; түүний үйлдлийг set()-ээр бүртгэнэ.

  $tui->set('Register', sub { my $form = shift; save($form); 0 });
  [Register]

[ 6. Товчлуурууд ]

  TAB/доош сум дараагийн талбар руу, Shift-TAB/дээш сум өмнөх талбар руу шилжинэ. Enter, Space болон сум товчлуурууд талбарыг засварлах эсвэл товчийг идэвхжүүлнэ; ESC маягтыг цуцална.

[ 7. Тэмдэгтийн кодчилол ]

  Windows бус систем дээр UTF-8, Windows дээр Shift_JIS (CP932) автоматаар танигдана; EUC-JP-г мөн дэмждэг. TUI_HANDY_ENCODING-ээр дарж бичих боломжтой.

  $ENV{TUI_HANDY_ENCODING} = 'euc';   # utf8 / sjis / euc

[ 8. Мөр горимын нөөц ]

  stty ашиглах боломжгүй үед (цэвэр Windows cmd.exe) зөөврийн мөр горимын драйвер автоматаар ашиглагдана; TUI_HANDY_MODE-ээр горимыг хүчээр тохируулна.

  $ENV{TUI_HANDY_MODE} = 'line';      # ansi / line

[ 9. Командын мөрийн хэрэглээ ]

  Perl код бичихгүйгээр DSL файлыг шууд ажиллуулах боломжтой.

  perl Handy.pm form.txt

[ 10. Бүрэн жишээ ]

  Бүх виджетийн төрлийг нэгтгэсэн богино DSL жишээ.

  Registration
  Company: [__________]
  Age:     [###]
  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium
  [Register]
