=head1 NAME

Acme::Parataxis::Ticker - Drift-Free Interval Timers for Scheduled Fibers

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async await_sleep];
    use Acme::Parataxis::Ticker;

    async {
        my $ticker = Acme::Parataxis::Ticker->new( interval => 1000 );    # 1 second ticks

        for ( 1 .. 5 ) {
            last unless my $tick_at = $ticker->wait_next;
            say "Tick at $tick_at; processing work...";
            await_sleep(250);    # work takes time, but ticker intervals do not drift!
        }

        $ticker->stop;           # stop the background ticker fiber
    };

=head1 DESCRIPTION

A standard loop of the form C<while (1) { do_work(); await_sleep($ms) }> suffers from cumulative timing drift: each
iteration takes C<$ms> I<plus> however long C<do_work()> took to execute. Over time, the schedule slides later and
later.

An C<Acme::Parataxis::Ticker> calculates intervals against absolute scheduled tick boundaries, sleeping only the
I<remainder> of each period. Ticks land on the boundary regardless of how long the consumer took to process the
preceding tick.

Under the hood, a private background fiber measures boundaries, sleeps the remainder of the interval, and pushes the
timestamp into a capacity-1 L<Acme::Parataxis::Channel>. Before publishing a new tick, any unread tick in the channel
is dropped. Exactly one tick is ever outstanding: a slow consumer silently drops missed intervals rather than
accumulating a stale backlog.

Calling C<stop()> terminates the ticker: any fiber parked in C<wait_next()> is unblocked and receives C<undef>, and the
background ticker fiber's sleep is interrupted so its background job is recalled immediately.

=head1 METHODS

=head2 C<new( interval =E<gt> $ms )>

    my $ticker = Acme::Parataxis::Ticker->new( interval => 500 );

Constructs a new ticker firing every C<$ms> milliseconds. The first tick lands one full interval after construction.
C<$ms> must be positive and defined.

Starts the internal background fiber immediately. Call C<stop()> when the ticker is no longer needed.

=head2 C<wait_next( )>

    while ( my $tick = $ticker->wait_next ) {
        execute_task();
    }

Parks the calling fiber until the next tick boundary arrives and returns that tick's scheduled timestamp. Returns
C<undef> once the ticker has been stopped. Must be called from within a scheduled fiber (croaks otherwise).

=head2 C<stop( )>

    $ticker->stop;

Stops the ticker. Halts publishing, releases any fiber currently waiting in C<wait_next()> with C<undef>, and
interrupts the background timer so no orphaned tasks remain in the thread pool. Idempotent. Returns true on the first
call.

=head2 C<running( )>

Returns true if the ticker is active; false if C<stop()> has been called.

=head2 C<interval( )>

Returns the configured interval in milliseconds.

=head2 C<pending( )>

Returns the number of unread ticks waiting in the channel (always C<0> or C<1>).

=head2 C<fired( )>

Returns the total count of ticks produced since construction.

=head2 C<dropped( )>

Returns the count of ticks superseded and dropped because a consumer did not collect them before the next interval
arrived.

=head2 C<skipped( )>

Returns the count of tick boundaries leapfrogged when the runtime woke significantly behind schedule. Skipped
boundaries are not counted as fired or dropped.

=head1 Recipes

=head2 Periodic maintenance loops

    async {
        my $ticker = Acme::Parataxis::Ticker->new( interval => 5000 );

        # Terminating loop: ends naturally when stop() is called:
        while ( my $t = $ticker->wait_next ) {
            prune_cache();
        }
    };

=head2 Virtual clock testing

Tickers integrate with C<Acme::Parataxis> virtual time under C<< run( virtual => 1 ) >>:

    Acme::Parataxis->run(
        virtual => 1,
        code    => sub {
            my $ticker = Acme::Parataxis::Ticker->new( interval => 1000 );
            my $ticks  = 0;

            fiber {
                while ( $ticker->wait_next ) { $ticks++ }
            };
            Acme::Parataxis->yield;

            # Fast-forward 3000ms virtually:
            Acme::Parataxis->advance(3000);
            Acme::Parataxis->yield;

            say "Ticks collected: $ticks";    # 3
            $ticker->stop;
        }
    );

=head1 Behavior Notes

=over

=item * Always call C<stop()>

An unstopped ticker maintains a background fiber waiting on future tick boundaries. Forgetting to call C<stop()> will
cause C<run()> to hang waiting for all fibers to drain.

=item * Exact boundary spacing

The timestamp returned by C<wait_next()> is the I<scheduled> boundary time, not the delivery time, keeping consecutive
timestamps evenly spaced even if a tick woke slightly late.

=back
