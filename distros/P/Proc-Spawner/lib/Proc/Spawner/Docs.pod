=head1 NAME

Proc::Spawner::Docs - a map of the design documents shipped in F<doc/> (EXPERIMENTAL)

=head1 DESCRIPTION

Besides the POD of its modules, the distribution ships its design notes as Markdown files under F<doc/>.
CPAN tools do not show those files as documentation, so this page lists them, says who wrote each one
and what it is for, and links to each twice on MetaCPAN: its name to the file, rendered, in the newest release;
"The same file in this release" (shown only in HTML) to the file of the release whose page you read, which
works from MetaCPAN's pages under F</release/.../view/> and F</dist/.../view/>, not from F</pod/...>.

The notes were written with Claude, at first by two working sessions with their own file prefixes: the
I<executor session> (prefix C<pspawn->: L<Proc::Spawner>, L<Proc::Spawner::Graph>, L<Proc::ShellSpawn>)
and the I<parser session> (prefix C<large-subset->: L<Proc::ShellSubset::Large>). Since 2026-11-02 one
session maintains everything. The base parser's notes (F<doc/parsers/>) come from an earlier session.

B<Status> words used below: I<current> (describes the code of this release), I<reference> (a rule set or
a procedure that stays valid), I<history> (kept for the record; may use the module names of its day:
C<ShellSpawn> is now L<Proc::ShellSpawn>, C<ShellSubsetLarge> is now L<Proc::ShellSubset::Large>, and so on).

=head2 Historical documents

The working documents of only historical interest (the investigation that started the large parser, the first
corpus statistics, the ceiling measurements, the reports between the sessions, the marks, why Run was replaced) are
in the Proc-Spawner 0.03 distribution on CPAN; this one no longer ships them.

=head2 Which version a figure belongs to

Every measured figure in these documents names the code it was measured on: I<pre-0.01> (the modules
under their former names, before the first distribution), I<0.01>, I<0.02> (the parsers of 0.01),
I<early-post-0.02> (0.02 plus items P1-P4 of the page "Shell Corpus Gaps", the evening of 2026-11-02;
that code was not kept), and I<0.03>.  The table is at the end of F<doc/README.md>.
