=encoding utf8

=head1 NAME

Acme::Parataxis::Local - Per-Fiber Storage Slots and Context Propagation

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async fiber];
    use Acme::Parataxis::Local;

    my $request_id = Acme::Parataxis::Local->new;
    my $trace_id   = Acme::Parataxis::Local->new( inherit => 1 );

    async {
        $request_id->set(42);
        $trace_id->set('span-100');

        fiber {
            # Inherited slot carries the parent's value at spawn time:
            say "Child trace:   " . $trace_id->get;      # span-100

            # Uninherited slot starts empty (undef):
            say "Child request: " . ($request_id->get // 'unset'); # unset

            $request_id->set(99);
            say "Child modified: " . $request_id->get;    # 99
        };

        # Parent's slot remains untouched:
        say "Parent request: " . $request_id->get;        # 42
    };

=head1 DESCRIPTION

C<Acme::Parataxis::Local> provides fiber-local storage, analogous to thread-local storage in multi-threaded runtimes. A
single C<Local> instance represents a variable that resolves to a private cell for each individual fiber.

Fibers never share or leak cells:

=over

=item * Writing to a C<Local> in a child fiber never overwrites the parent's or siblings' values.

=item * Unlike Perl's dynamic C<local>, the value follows the fiber's execution lifetime rather than the block scope.
It survives any number of C<await> and C<yield> boundaries.

=item * When a fiber terminates and is reaped, its local cells are cleaned up automatically, avoiding memory leaks in
long-running processes.

=back

=head1 Inheritance and Trace Propagation

Constructing a slot with C<inherit =E<gt> 1> enables automatic context propagation. When a fiber spawns a child fiber
via C<fiber { ... }>, C<spawn()>, an actor, or a nursery, all active inherited slots are shallow-copied into the
child's cell before its first statement runs.

This is the standard mechanism for passing request IDs, tracing spans, and security contexts down an asynchronous call
tree without manually threading parameters through every helper function. Once copied, the child owns its cell
outright; subsequent writes by parent or child do not cross the boundary.

=head1 METHODS

=head2 C<new( [%opts] )>

    my $plain  = Acme::Parataxis::Local->new;
    my $seeded = Acme::Parataxis::Local->new( default => 'anonymous' );
    my $traced = Acme::Parataxis::Local->new( inherit => 1 );

Constructs a new fiber-local slot. Arguments are keyword-only:

=over

=item * C<default =E<gt> $val>

The fallback value returned by C<get()> in fibers that have not explicitly set a value. Default is C<undef>.

=item * C<inherit =E<gt> $bool>

If true, child fibers spawned via C<spawn()>, C<fiber>, nurseries, or actors inherit a snapshot of the parent's current
value at spawn time. Default is false.

=back

=head2 C<get( )>

    my $val = $slot->get;

Returns the value stored in the calling fiber's private cell, or the configured C<default> if unwritten.

Must be called from within a scheduled fiber (croaks with C<Local->get must be called from inside a scheduled fiber>
otherwise).

=head2 C<set( $value )>

    $slot->set('req-123');

Stores C<$value> in the calling fiber's private cell and returns that value. The write is strictly private to this
fiber.

Must be called from within a scheduled fiber (croaks otherwise).

=head1 Recipes

=head2 Contextual logging without parameter threading

    use v5.40;
    use Acme::Parataxis qw[async fiber];
    use Acme::Parataxis::Local;

    my $CURRENT_USER = Acme::Parataxis::Local->new( default => 'guest', inherit => 1 );

    sub log_action ($action) {
        my $user = $CURRENT_USER->get;
        say "[$user] $action";
    }

    async {
        $CURRENT_USER->set('alice');
        log_action('logging in');    # [alice] logging in

        fiber {
            # Inherited context carries into background work:
            log_action('processing queue');    # [alice] processing queue
        };
    };

=head2 Isolated fiber-scoped resource handles

    my $DB_CONN = Acme::Parataxis::Local->new;

    sub get_db () {
        my $dbh = $DB_CONN->get;
        unless ($dbh) {
            $dbh = create_database_handle();
            $DB_CONN->set($dbh);
        }
        return $dbh;
    }

    # Concurrent fibers calling get_db() each maintain an isolated connection.

=head1 Behavior Notes

=over

=item * Top-level C<async> blocks do not inherit

Inheritance is wired into C<spawn()>. Because C<async { ... }> and C<run()> initialize a brand-new scheduler run
directly rather than spawning off a parent fiber, they do not inherit slots from an enclosing context. Pass values into
an C<async> block explicitly or wrap the work in an internal C<fiber { ... }>.

=item * Writing C<undef> overrides the default

C<default> is only consulted when a fiber has never called C<set()>. Calling C<< $slot->set(undef) >> stores an
explicit undefined value, and subsequent C<get()> calls return C<undef>, not the default.

=item * Unique slot identity

Each instantiated C<Local> object receives a monotonically increasing process-wide ID. Two distinct C<Local> instances
with identical configurations remain completely isolated from one another.

=back
