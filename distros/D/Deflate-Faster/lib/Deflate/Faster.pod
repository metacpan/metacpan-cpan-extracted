=encoding utf-8

=head1 Name

Deflate::Faster - fast gzip, zlib and raw DEFLATE using libdeflate

=head1 Synopsis

    use Deflate::Faster qw(:all);

    my $gz    = gzip($data);          # optional level: gzip($data, 1)
    my $plain = gunzip($gz);

    my $z   = deflate($data);         # zlib (RFC 1950)
    my $raw = deflate_raw($data);     # raw DEFLATE (RFC 1951)

    gzip_to_file($data, 'out.gz');
    my $back = gunzip_file('out.gz');

    my $df = Deflate::Faster->new;
    $df->level(1);
    $df->max_size(10 * 1024 * 1024);
    my $out = $df->zip($data);
    my $in  = $df->unzip($out);

=head1 Description

A drop-in replacement for L<Gzip::Faster> built on
L<libdeflate|https://github.com/ebiggers/libdeflate>. Compression and
decompression work on whole buffers in memory. Levels run from 0 (stored) to
12, default 6. Compressor and decompressor states are cached per thread.

=head1 Functions

=head2 gzip, deflate, deflate_raw

    my $out = gzip($plain, $level);

Compress to gzip, zlib or raw DEFLATE. C<$level> is optional; C<undef> or
C<-1> selects the default. Undefined or empty input warns and returns
C<undef>.

=head2 gunzip, inflate, inflate_raw

    my $plain = gunzip($zipped);

Decompress. C<gunzip> also accepts zlib streams and concatenated gzip
members, and checks header CRCs. Corrupt, truncated or trailing data croaks.
Undefined or empty input warns and returns C<undef>.

=head2 gzip_file

    my $zipped = gzip_file($file, %options);

Options: C<level>, C<file_name> (default C<$file>), C<mod_time> (default the
file's mtime) and C<copy_perl_flags>. Pass C<< file_name => '' >> or
C<< mod_time => 0 >> to omit them.

=head2 gunzip_file

    my $plain = gunzip_file($file, %options);

Options: C<max_size>, C<copy_perl_flags>, and scalar references
C<< file_name => \$name >> and C<< mod_time => \$mtime >> to receive the
header fields.

=head2 gzip_to_file, gunzip_to_file

    gzip_to_file($plain, $file, %options);
    gunzip_to_file($zipped, $file, %options);

Write the result to C<$file>, truncating it. C<gzip_to_file> takes the
C<gzip_file> options without their defaults; C<gunzip_to_file> takes
C<max_size> and always writes bytes.

=head1 Methods

=head2 new

    my $df = Deflate::Faster->new;

=head2 zip, unzip

    my $out   = $df->zip($plain);
    my $plain = $df->unzip($out);

Use the object's format and settings. C<zip> writes C<file_name> and
C<mod_time> into the gzip header, then clears C<file_name>. C<unzip> clears
both, then sets them from the first gzip member's header.

=head2 gzip_format, raw

    $df->gzip_format(1);
    $df->raw(1);

Select gzip (the default) or raw DEFLATE. With both off the format is zlib.

=head2 level

    $df->level($level);

0 to 12. C<undef> or C<-1> selects 6; lower values warn and select 6;
higher values warn and select 12.

=head2 max_size

    $df->max_size($bytes);

Croak when decompressed output would exceed C<$bytes>. Values below 1 and
C<undef> mean unlimited; strings convert as Perl numbers do. Without a limit,
a gzip trailer claiming a large size can make a buffer grow to 8 times the
output already decoded.

=head2 file_name

    $df->file_name($name);
    my $name = $df->file_name;

Gzip header file name, stored as Latin-1 and cut at the first NUL. A name
with characters beyond Latin-1 croaks at C<zip>.

=head2 mod_time

    $df->mod_time($epoch);
    my $epoch = $df->mod_time;

Gzip header time, an unsigned 32-bit integer. Out-of-range and non-numeric
values warn and are clamped.

=head2 copy_perl_flags

    $df->copy_perl_flags(1);

Record Perl's UTF-8 flag in the gzip header, in the same format as
L<Gzip::Faster>, and restore it on C<unzip> when any member carries it and
the output is valid UTF-8. Gzip format only.

=head1 Differences from Gzip::Faster

=over 4

=item * Concatenated gzip members decompress; Gzip::Faster croaks.

=item * Trailing bytes after a stream croak.

=item * Header CRCs (FHCRC) are checked.

=item * Levels 0 to 12, and the procedural functions take an optional level.

=item * C<unzip> clears C<file_name> and C<mod_time> in every format.

=item * C<gzip_file> keeps its file name and mtime defaults when other
options are given.

=item * File names are written as Latin-1; wider characters croak.

=item * C<mod_time> is clamped to 32 bits instead of wrapping.

=item * C<new> blesses into the calling subclass.

=item * The custom header OS byte is C<0xff>, and error messages differ.

=back

=head1 Diagnostics

=over 4

=item C<Empty input>

=item C<Attempt to compress empty string>

=item C<Attempt to uncompress empty string>

(W) Undefined or empty input; C<undef> is returned.

=item C<Data input to inflate is not in libz format>

(F) Corrupt, truncated or trailing data.

=item C<Uncompressed data exceeds max_size of %d bytes>

(F) See L</max_size>.

=item C<Gzip file_name must contain only Latin-1 characters>

(F) See L</file_name>.

=item C<Cannot set compression level to less than 0>

=item C<Cannot set compression level to more than 12>

=item C<Argument "%s" isn't numeric in compression level>

=item C<Cannot set modification time to less than 0>

=item C<Cannot set modification time to more than 4294967295>

=item C<Argument "%s" isn't numeric in modification time>

(W) See L</level> and L</mod_time>.

=item C<Cannot write file name to non-scalar reference>

=item C<Cannot write modification time to non-scalar reference>

(W) A C<gunzip_file> option was not a scalar reference.

=back

=head1 Performance

Speed relative to Gzip::Faster on Linux x86_64, averaged over eight kinds of
text per size (C<bench/bench_vs_gzip_faster.pl>):

    size     gzip level 6   gzip level 1   gunzip
    72 B          5.8x           7.2x        1.0x
    2 KB          3.6x           6.4x        1.3x
    100 KB        1.3x           4.1x        3.4x
    1 MB          1.4x           4.4x        3.4x

=head1 Threads

Cached engines are freed when their thread exits. Objects are not cloned
into new threads.

=head1 Exports

C<gzip>, C<gunzip>, C<gzip_file>, C<gunzip_file> and C<gzip_to_file> by
default; C<deflate>, C<inflate>, C<deflate_raw>, C<inflate_raw> and
C<gunzip_to_file> on request; C<:all> for everything.
