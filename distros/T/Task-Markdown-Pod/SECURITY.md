# Security Policy

Security fixes are normally made against the latest CPAN release.

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/aspeer/pm-Task-Markdown-Pod/security/advisories/new).
If that is unavailable, contact Andrew Speer at
<andrew.speer@isolutions.com.au>. Do not disclose vulnerabilities through a
public issue or pull request, and do not include credentials or unrelated
private data.
