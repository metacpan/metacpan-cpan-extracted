MY	[MY] မြန်မာဘာသာ	ထည့်သွင်းခြင်းနှင့် ဖွင့်ခြင်း	ဖောင်ဖန်တီးပြီး အလုပ်လုပ်ခြင်း	စာသားဘောက်စ် သင်္ကေတများ	ချက်ဘောက်စ်နှင့် ရေဒီယိုခလုတ်	ခလုတ်	ခလုတ်များ	အက္ခရာ ကုဒ်နံပါတ်	လိုင်းမုဒ် အရန်စနစ်	command line အသုံးပြုခြင်း	ပြည့်စုံသော ဥပမာ	ကိုးကားချက်များ	CPAN မှီခိုမှု မရှိပါ။ Handy.pm ကို @INC ထဲမှ ဒါရိုက်တိုရီတစ်ခုသို့ ကူးယူပါ၊ သို့မဟုတ် script အနေဖြင့် တိုက်ရိုက် မောင်းနှင်ပါ။	DSL string သို့မဟုတ် ဖိုင်တစ်ခုမှ ဖောင်ကို တည်ဆောက်ပြီး run() ကို ခေါ်ပါ။ ရလဒ်မှာ DSL ရှိ label များကို key အဖြစ်အသုံးပြုသော hash reference တစ်ခုဖြစ်သည်။	[ ] အတွင်းရှိ ဖြည့်စွက်အက္ခရာများက စာသားဘောက်စ် အမျိုးအစားကို ရွေးချယ်သည်- _ သည် ထက်ဝက်အကျယ်၊ # သည် ဂဏန်း၊ $ သို့မဟုတ် \ သည် ငွေကြေး၊ YYYYMMDD သို့မဟုတ် % သည် ရက်စွဲ၊ ပြည့်အကျယ် အက္ခရာမည်သည့်အရာမဆို zenkaku အမျိုးအစားအတွက်ဖြစ်သည်။	[X]/[ ] သည် ချက်ဘောက်စ်ဖြစ်သည် (တန်ဖိုး 1 သို့မဟုတ် 0)။ (*)/( ) သည် ယခင်ခေါင်းစဉ်လိုင်းအလိုက် ရေဒီယိုခလုတ်များကို အုပ်စုဖွဲ့ပြီး တန်ဖိုးမှာ ရွေးချယ်ထားသော label စာသားဖြစ်သည်။	label စာသား မရှိသော လေးထောင့်ကွင်းသည် ခလုတ်တစ်ခုဖြစ်သည်။ ၎င်း၏ လုပ်ဆောင်ချက်ကို set() ဖြင့် မှတ်ပုံတင်ပါ။	TAB/ အောက်မြား နောက်ကွက်သို့သွားပြီး Shift-TAB/ အပေါ်မြားသည် ယခင်ကွက်သို့သွားသည်။ Enter၊ Space နှင့် မြားခလုတ်များသည် ကွက်ကို တည်းဖြတ်ခြင်း သို့မဟုတ် ခလုတ်ကို အသက်သွင်းခြင်းဖြစ်ပြီး ESC သည် ဖောင်ကို ရပ်တန့်စေသည်။	Windows မဟုတ်သော စနစ်များတွင် UTF-8 နှင့် Windows တွင် Shift_JIS (CP932) ကို အလိုအလျောက် သိရှိသည်။ EUC-JP ကိုလည်း ပံ့ပိုးသည်။ TUI_HANDY_ENCODING ဖြင့် ပြင်ဆင်နိုင်သည်။	stty မရရှိနိုင်သောအခါ (စစ်စစ် Windows cmd.exe) သယ်ဆောင်ရလွယ်ကူသော လိုင်းမုဒ် driver ကို အလိုအလျောက် အသုံးပြုသည်။ TUI_HANDY_MODE ဖြင့် မုဒ်ကို အတင်းသတ်မှတ်ပါ။	Perl ကုဒ် မရေးဘဲ DSL ဖိုင်တစ်ခုကို တိုက်ရိုက် မောင်းနှင်နိုင်သည်။	widget အမျိုးအစားအားလုံးပေါင်းစပ်ထားသော DSL ဥပမာ တိုတိုလေး။	အပြည့်အစုံ စာရွက်စာတမ်းသည် lib/TUI/Handy.pm ၏ POD တွင်ရှိသည် (perldoc TUI::Handy)။ စာရေးသူ: INABA Hitoshi <ina.cpan@gmail.com>။ လိုင်စင်: Perl နှင့်တူညီသောစည်းကမ်းများ။
