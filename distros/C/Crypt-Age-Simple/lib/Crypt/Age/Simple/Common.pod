=head1 NAME

Crypt::Age::Simple::Common - Helper functions for Crypt::Age::Simple


=head1 SYNOPSIS

   use Crypt::Age::Simple::Common qw< :constants :misc :scrypt :x25519 >;


=head1 DESCRIPTION

This module provides helper functions for other modules across the
distribution.

=head1 INTERFACE

The interface is function-oriented. Functions can be imported by name or
in groups, like C<:constants> or C<:misc>.

=head2 Constants

The following functions belong to group C<:constants>.

=over

=item C<< CHUNK_SIZE >>

=item C<< NONCE_SIZE >>

=item C<< SCRYPT_SALT_PREFIX >>

=item C<< TAG_SIZE >>

=item C<< VERSION_LINE >>

=back


=head2 scrypt

=over

=item C<< age_scrypt_decrypter >>

L<Crypt::Age::Simple::Decrypt> constructor aimed at scrypt.

=item C<< age_scrypt_encrypter >>

L<Crypt::Age::Simple::Encrypt> constructor aimed at scrypt.

=item C<< age_scrypt_unwrap_file_key >>

   my $file_key = age_scrypt_unwrap_file_key($stanza, $password);

=item C<< age_scrypt_wrap_key >>

   my $key = age_scrypt_wrap_key($password, $salt, $Nlog2);

C<$Nlog2> is the base-2 logarithm of the scrypt work factor.

=back

=head2 x25519

=over

=item C<< age_x25519_decrypter >>

L<Crypt::Age::Simple::Decrypt> constructor aimed at X25519.

=item C<< age_x25519_encrypter >>

L<Crypt::Age::Simple::Encrypt> constructor aimed at X25519.

=back

=head2 Miscellanea

=over

=item C<< age_base64_multiline >>

Base-64 without padding and with lines no longer than 64 characters.

=item C<< age_primitives_make_nonce >>

=item C<< buffer >>

Wrapper around L<Crypt::Age::Simple::Buffer>.

=back
