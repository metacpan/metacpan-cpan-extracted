=head1 NAME

MojoX::Authentication::Model::SAML2::Hash


=head1 SYNOPSIS

   use MojoX::Authentication::Model::SAML2::Hash;

   my $cache = MojoX::Authentication::Model::SAML2::Hash;

   my $data = {...};
   $cache->set($data, $key, $expiration_time);
   
   my $data_out = $cache->get($key);

   $cache->wipe($key);


=head1 DESCRIPTION

Cache for data, based on a hash local to the process.

This is the default cache for L<MojoX::Authentication::Model::SAML2>.
As data is not shared among processes, it is only suitable for
applications running as a single process; with C<hypnotoad>, the
C<prefork> command or any other multi-process setup, use
L<MojoX::Authentication::Model::SAML2::Db> instead (see
L<MojoX::Authentication::Model::SAML2/create>).

=head1 INTERFACE

=head2 B<< get >>

   my $data = $cache->get($key);

Retrieve an object from the cache, by key.

=head2 B<< new >>

   my $cache = MojoX::Authentication::Model::SAML2::Hash->new;

Constructor for an object.

=head2 B<< set >>

   $cache->set($data, $key, $expiration_time);

Set an element in the cache, with expiration time (expressed as an
epoch). Every call also removes the entries that have already
expired, so that abandoned logins do not pile up.

=head2 B<< wipe >>

   $cache->wipe($key);

Permanently remove an item from the cache.
