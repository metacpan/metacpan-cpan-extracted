=head1 NAME

Acme::Parataxis::Signal - One-Shot Event Flags with Waiter Queues

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async fiber];
    use Acme::Parataxis::Signal;

    # Initialize unsignalled (count => false):
    my $ready = Acme::Parataxis::Signal->new( count => false );

    async {
        fiber {
            say 'Worker: waiting for ready signal...';
            $ready->wait;    # parks until signalled
            say 'Worker: unblocked and running!';
        };

        say 'Main: completing setup...';
        $ready->send;        # wakes the worker fiber
    };

=head1 DESCRIPTION

An C<Acme::Parataxis::Signal> represents a single notification flag accompanied by a FIFO queue of waiters. Calling
C<send> signals the event, waking a parked fiber or saving the notification for the next fiber that arrives.

A key design feature of signals is B<early firing safety>: if C<send> is called before any fiber has called C<wait>,
the signal is remembered. When a fiber eventually calls C<wait>, it consumes the remembered signal and proceeds
immediately without parking. This eliminates initialization race conditions where a notifier fires before its listeners
are spawned.

=over

=item *

C<send()> releases B<one> waiter, or records the signal if no waiters exist.

=item *

C<broadcast()> wakes B<all> currently queued waiters simultaneously, clearing any remembered signal.

=back

=head1 METHODS

=head2 C<new( [ count =E<gt> $bool = true ] )>

    my $ready = Acme::Parataxis::Signal->new( count => false );   # unsignalled (common case)
    my $fired = Acme::Parataxis::Signal->new;                     # pre-signalled

Constructs a new signal.

B<Important Default>: C<count> defaults to B<true> (pre-signalled). In this state, the first C<wait()> will not block.
For the standard pattern where waiters must park until an event occurs, pass C<< count => false >>.

=head2 C<send( )>

    $signal->send;

Delivers the signal to the longest-waiting entity (waking a parked fiber or executing a registered callback). If no
waiters are currently queued, the signal is stored (setting C<count> to true) so the next C<wait()> will return
immediately. Returns true.

=head2 C<broadcast( )>

    $signal->broadcast;

Wakes every currently queued waiter in a single pass. Unlike C<send()>, an unconsumed broadcast is not remembered: if
no waiters are present, the notification is discarded, and any previously banked signal is cleared (resetting C<count>
to false). Returns true.

=head2 C<wait( [$callback] )>

    $signal->wait;            # parks the calling fiber until signalled
    $signal->wait(\&on_done); # registers a callback without parking

=over

=item *

B<Without arguments>: If a signal is already pending, consumes it (resetting C<count> to false) and returns
immediately. Otherwise, parks the calling fiber until a signal arrives. Always returns C<undef>. Must run inside a
scheduled fiber unless a signal is already pending.

=item *

B<With a CODE reference>: Registers C<$callback> to run when the signal fires, returning immediately without parking.
If a signal is already pending, the callback executes inline before C<wait()> returns. Safe to call outside a fiber.

=back

=head2 C<awaited( )>

    my $num_waiters = $signal->awaited;

Returns the total count of currently queued waiters (parked fibers plus registered callbacks). Returns 0 when no
waiters are waiting.

=head2 C<count( )>

Returns true if a signal has been banked and is currently pending consumption; false otherwise.

=head2 C<remove_waiter( $waiter )>

    $signal->remove_waiter($cb_or_fid);

Removes a specific callback or fiber ID from the wait queue without triggering it. Used during cancellation and
cleanup.

=head1 Recipes

=head2 Fan-out broadcast notification

Use C<broadcast()> to release multiple concurrent workers on a single event:

    async {
        my $start_signal = Acme::Parataxis::Signal->new( count => false );

        for my $id ( 1 .. 3 ) {
            fiber {
                $start_signal->wait;
                say "Worker $id running!";
            };
        }

        await_sleep(50);
        say "Starting all workers:";
        $start_signal->broadcast;    # unblocks all 3 workers at once
    };

=head2 Non-blocking callback triggers

Register callbacks to execute immediately upon notification without spawning intermediate fibers:

    my $done = Acme::Parataxis::Signal->new( count => false );

    $done->wait( sub {
        say "Cleanup callback executed inline on send()";
    } );

    # Later, in any fiber:
    $done->send;

=head1 Behavior Notes

=head2 C<broadcast( )> cancels banked signals

C<broadcast()> clears any pending signal flag even if no waiters were queued. If you need to clear the wait queue while
preserving a banked signal, invoke C<send()> repeatedly for each waiter instead.

=head2 Single wake-up per C<send( )>

Calling C<send()> multiple times while no fibers are waiting will only bank a single notification. The signal records
I<that> it fired, not I<how many times> it fired. For event counting, use L<Acme::Parataxis::Semaphore> or
L<Acme::Parataxis::Channel>.

=head2 Inline callback execution

Callbacks registered with C<< wait(\&cb) >> run synchronously inside C<send()> or C<broadcast()>, in the context of the
signaling fiber. If a registered callback dies, the exception propagates directly out of C<send()>, interrupting the
broadcast loop and stranding any remaining queued waiters.
