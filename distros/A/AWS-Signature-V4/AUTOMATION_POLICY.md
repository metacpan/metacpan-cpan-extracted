The goal of this module is to support AWS's Signature version 4 in a way
that is not tied to a specific framework (like `LWP`, `Mojo::UserAgent`,
etc.) but at the same time support all the different variants, with
specific reference to X509 certificates.

As the module is already expected to support all these use cases,
contributions are expected only to fix bugs or add stuff that is within
the boundaries but that for some reason has been left out.

Contributions can be produced with AI; in this case:

1. They MUST be compact enough to be suitable for human revision
2. They MUST be sequential: wait for a feedback on a contribution before
proposing a different one.
