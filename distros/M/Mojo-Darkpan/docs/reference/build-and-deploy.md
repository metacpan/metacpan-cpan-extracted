# Build and deploy

## Dist tooling

| File | Role |
|------|------|
| `minil.toml` | Minilla config: `ModuleBuildTiny`, excludes `^config.json` from the dist |
| `Build.PL` | Generated by Minilla (Module::Build::Tiny) |
| `META.json` | Generated metadata |
| `cpanfile` | Runtime deps (IO::Zlib, JSON, Mojolicious, Mojolicious::Plugin::BasicAuthPlus, Mojo::File, Moo, OrePAN2, Syntax::Keyword::Try); `perl` v5.20; test dep Test::More 0.98 |
| `Changes` | Minilla changelog, `{{$NEXT}}` marker |

## Docker (`Dockerfile`, `.dockerignore`)

Uncommitted rewrite in the working tree as of 2026-10-22. Built and run with podman 5.8.2: publish, `/list` and delivery returned 200 and the process ran as `darkpan`.

- Two stages on `perl:${PERL_VERSION}-slim-threaded` (arg default `5.44`). Compile stage installs build tools and runs `cpm install --global` from `cpanfile`; final stage copies `/usr/local`, then `lib/` and `script/`.
- Runtime packages: `git`, `openssh-client`, `libssl3`, `zlib1g`, `ca-certificates`.
- Runs as user `darkpan`; `DARKPAN_DIRECTORY=/opt/darkpan`, declared `VOLUME`; `EXPOSE 3000`.
- `CMD ["perl", "script/darkpan", "--port", "3000"]`.

## Release and CI

- Release flow is Minilla-based (`[release]` in `minil.toml`); steps beyond that are not documented in the repo.
- `.github/workflows/test.yml` runs `prove -lr t` on Perl 5.26, 5.32, 5.38, 5.40 and 5.44 for pushes to `main` and pull requests. *(not yet run on GitHub)* `.travis.yml` was removed.
- `.idea/` project files are tracked.
