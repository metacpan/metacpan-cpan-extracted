# Contributing to Task::Markdown::Pod

Bug reports and focused contributions are welcome through the public
[GitHub repository](https://github.com/aspeer/pm-Task-Markdown-Pod).

Run `perl Makefile.PL`, `make test`, and `make disttest` before submitting a
pull request. Do not include credentials or private data. Report potential
vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
