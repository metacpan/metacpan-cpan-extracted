=head1 NAME

Crypt::Age::Simple::Decrypt - Streaming decrypter for Crypt::Age::Simple


=head1 SYNOPSIS

   use Crypt::Age::Simple::Decrypt;

   # initialize with scrypt of X25519 "identities"
   my $decrypter = Crypt::Age::Simple::Decrypt->new(
      identity => { scrypt => $password },
      max_header_size => 150, # standard size of a scrypt header
   );
   my $decrypter = Crypt::Age::Simple::Decrypt->new(
      identity => { X25519 => $identity },
   );

   # you can give data in as a plain scalar
   $decrypter->pump($some_ciphertext_as_string);

   # data out is in an array of references to scalars
   my $aref = $decrypter->get_chunks;
   my $cleartext = join '', { $$_ } $aref->@*;

   # pump() works with scalar reference too, for minimal copying around
   $decrypter->pump(\$some_ciphertext_as_reference);

   # finish() marks the end of the ciphertext so that the last chunks
   # can also be properly decrypted
   $decrypter->finish;

   # again, get_chunks gives back an array of scalar references
   $cleartext .= join '', { $$_ } $decrypter->get_chunks->@*;


=head1 DESCRIPTION

This module provides a streaming interface for age decryption (see
L<age|https://age-encryption.org/>).

=head1 INTERFACE

The interface is object-oriented. A typical usage is like this:

=over

=item *

Create an object instance via L</new>.

=item *

Alternate L</pump> and L</get_chunks>.

=item *

Call L</finish> and then L</get_chunks> one last time.

=back

Methods:

=begin hide

=head2 B<< BUILDARGS >>

Not really a sub part of the public interface.

=end hide

=head2 B<< finish >>

   $obj->finish;

Mark the data provision as completed, i.e. no more L</pump>. It is
I<necessary> to call this method in order to get the final chunk from
L</get_chunks>.

=head2 B<< identity >>

   my $id = $self->identity;

The identity to use for decryption (technically, to derive the file key).

Accepts:

=over

=item *

Code reference. It is called with the parsed C<$header> as the only input
argument and it is supposed to return the file key.

=item *

Array reference (assumes C<X25519>), holding a list of identities (private
keys).

=item *

Plain scalar (assumes C<scrypt>), holding a password.

=item *

Hash reference. It is assumed to only hold a key/value pair, the key being
the I<type>. Currently supported: C<scrypt>, C<X25519>, C<x25519>. The
value holds the corresponding input value.

=back

=head2 B<< is_complete >>

   my $bool = $obj->is_complete;

Boolean value representing whether the decryption is complete or if it
still has data to extract.

=head2 B<< is_error >>

   my $bool = $obj->is_error;

Boolean value representing if the object is in a state of error, e.g. for
bad parsing or unmatched identities.

=head2 B<< max_header_size >>

   my $value = $obj->max_header_size;

Maximum size allowed for the header. Its value is set upon construction
(see L</new>). Setting a maximum value is a security measure against
abuse.

=head2 B<< new >>

   my $obj = Crypt::Age::Simple::Decrypt->new($identity); # OR
   my $obj = Crypt::Age::Simple::Decrypt->new(\%args); # OR
   my $obj = Crypt::Age::Simple::Decrypt->new(%args); # OR
   my $obj = Crypt::Age::Simple::Decrypt->new($identity, %args);

Constructor.

Arguments can be passed as a hash reference or a list of key/value pairs.
If the list of arguments holds an odd number of elements, the first is
considered associated to the C<identity> key.

The following keys are valid:

=over

=item *

C<identity> the identity used to unwrap the file key, see L</identity>.
This argument is I<required>.

=item *

C<max_header_size> the maximum size allowed for the header, as a security
measure. See also accessor L</max_header_size>.

=back

=head2 B<< get_chunks >>

   my $aref = $obj->get_chunks; # OR
   my $aref = $obj->get_chunks($n);

Get at most C<$n> available chunks of decrypted data, or all of them if
C<$n> is missing or otherwise false.

Dies if the object is in a state of error.

Returns an array reference holding scalar references, pointing to the
decrypted data.

=head2 B<< has_header >>

   my $bool = $obj->has_header;

Boolean test to check if the header has already been parsed or not.

=head2 B<< header >>

   my $header = $obj->header;

The parsed header, if already available.

=head2 B<< pump >>

   $obj->pump($scalar); # OR
   $obj->pump(\$scalar); # OR
   $obj->pump(\@array_of_scalar_refs);

Add data to the object. Depending on what you have, you can pass it as
scalar, ref to scalar, or ref to an array holding scalar refs.

After passing the final part of the data make sure to call L</finish> or
L</get_chunks> will never give you back the last chunk of decrypted
plaintext.

Minimum perl version 5.24.
