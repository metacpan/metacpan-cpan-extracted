[ 1. ස්ථාපනය සහ පූරණය ]

  CPAN යැපීමක් නොමැත; Handy.pm ගොනුව @INC තුළ ඕනෑම නාමාවලියකට පිටපත් කරන්න, නැතහොත් එය කෙලින්ම ස්ක්‍රිප්ට් එකක් ලෙස ධාවනය කරන්න.

  use TUI::Handy;
  # or, as a command:  perl Handy.pm form.txt

[ 2. පෝරමයක් තැනීම සහ ධාවනය ]

  DSL පෙළ තන්තුවකින් හෝ ගොනුවකින් පෝරමය තනා, පසුව run() ඇමතුම ලබා දෙන්න; ප්‍රතිඵලය වන්නේ DSL හි ලේබල් යතුරු ලෙස ඇති hash යොමුවකි.

  my $tui  = TUI::Handy->new(dsl => $text);   # or new(file => $path)
  my $form = $tui->run;
  print "Company = $form->{Company}\n";

[ 3. පෙළ පෙට්ටියේ සලකුණු ]

  [ ] තුළ ඇති පිරවුම් අනුලකුණු පෙළ පෙට්ටියේ වර්ගය තෝරයි: _ අර්ධ-පළල, # අංකය, $ හෝ \ මුදල්, YYYYMMDD හෝ % දිනය, සහ පූර්ණ-පළල ඕනෑම අනුලකුණක් zenkaku වර්ගය සඳහා.

  Company: [__________]
  Age:     [###]
  Price:   [$$$$$$]
  Date:    [YYYYMMDD]

[ 4. චෙක්බොක්ස් සහ රේඩියෝ බොත්තම ]

  [X]/[ ] යනු චෙක්බොක්සයකි (අගය 1 හෝ 0); (*)/( ) පෙර ශීර්ෂ රේඛාව අනුව රේඩියෝ බොත්තම් සමූහගත කරයි, අගය තෝරාගත් ලේබල් පෙළ වේ.

  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium

[ 5. බොත්තම ]

  ඉදිරියෙන් ලේබල් පෙළක් නොමැති හතරැස් වරහන් බොත්තමකි; එහි ක්‍රියාව set() මගින් ලියාපදිංචි කරන්න.

  $tui->set('Register', sub { my $form = shift; save($form); 0 });
  [Register]

[ 6. යතුරු ]

  TAB/pahala pihiya ඊළඟ ක්ෂේත්‍රයට, Shift-TAB/uda pihiya පෙර ක්ෂේත්‍රයට යයි. Enter, Space සහ ඊතල යතුරු ක්ෂේත්‍රය සංස්කරණය කරයි හෝ බොත්තම සක්‍රීය කරයි; ESC පෝරමය නවත්වයි.

[ 7. අනුලකුණු කේතනය ]

  Windows නොවන පද්ධතිවල UTF-8 සහ Windows හි Shift_JIS (CP932) ස්වයංක්‍රීයව හඳුනාගනී; EUC-JP ද සහාය දක්වයි. TUI_HANDY_ENCODING මගින් අභිබවා යා හැක.

  $ENV{TUI_HANDY_ENCODING} = 'euc';   # utf8 / sjis / euc

[ 8. රේඛා-ප්‍රකාර විකල්පය ]

  stty නොමැති විට (පිරිසිදු Windows cmd.exe), අතේ ගෙන යා හැකි රේඛා-ප්‍රකාර ධාවකයක් ස්වයංක්‍රීයව භාවිත වේ; TUI_HANDY_MODE මගින් ප්‍රකාරය බල කරන්න.

  $ENV{TUI_HANDY_MODE} = 'line';      # ansi / line

[ 9. විධාන රේඛා භාවිතය ]

  කිසිදු Perl කේතයක් නොලියා DSL ගොනුවක් කෙලින්ම ධාවනය කළ හැක.

  perl Handy.pm form.txt
