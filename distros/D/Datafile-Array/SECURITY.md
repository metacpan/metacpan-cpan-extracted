# Security Policy for Datafile-Array

This is the Security Policy for the Perl Datafile-Array distribution.

## Reporting a Vulnerability

Report security issues via email to hans at atbas.org.

Please do **not** report security vulnerabilities in public forums, codeberg.org issues, or RT.

The author will respond and release fixes as soon as possible.  
However, this project is maintained by a single volunteer in their spare time and cannot guarantee a rapid response.

If the issue is urgent or you receive no reply within a reasonable time, you may also notify the CPAN Security Group (CPANSec) at <cpan-security@security.metacpan.org>.

## Supported Versions

Only the latest release of Datafile-Array is supported.
