# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in WebService::Mailgun, do not open a public issue. Report it through GitHub's [Private vulnerability reporting](https://github.com/kan/p5-web-service-mailgun/security/advisories/new) instead. Only the maintainer can see the report until a fix is published.

Please include:

- What the vulnerability is
- Steps to reproduce it
- The expected impact (for example, the Mailgun API key leaking into logs or to a third party)

Reports are checked and answered as soon as possible.

## Scope

In scope are the code in this repository and the [WebService-Mailgun](https://metacpan.org/dist/WebService-Mailgun) distribution on CPAN. Fixes are released only for the latest version.

Please report these elsewhere:

- Problems in the Mailgun service itself: [Mailgun](https://www.mailgun.com/)
- Vulnerabilities in other dependencies: the project that publishes the dependency
