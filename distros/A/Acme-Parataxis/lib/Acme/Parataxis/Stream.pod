=encoding utf8

=head1 NAME

Acme::Parataxis::Stream - Chainable Async FRP Streams over Bounded Channels

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async];
    use Acme::Parataxis::Channel;
    use Acme::Parataxis::Stream;

    async {
        my $raw = Acme::Parataxis::Channel->new( capacity => 1024 );

        # Build and consume an asynchronous stream pipeline:
        my $sink = Acme::Parataxis::Stream->from_channel($raw)
            ->map(     sub ($json)  { decode_json($json)      } )
            ->filter(  sub ($item)  { $item->{priority} > 1   } )
            ->throttle(100)                                   # max 100 items/sec
            ->batch_time(1000)                                # group into 1-sec batches
            ->consume( sub (@batch) { db_bulk_insert(@batch) } );

        # Produce data into the source channel:
        $raw->put($_) for @events;
        $raw->shutdown;

        # Await the pipeline sink until all stages drain:
        $sink->await;
    };

=head1 DESCRIPTION

An C<Acme::Parataxis::Stream> is a chainable pipeline of asynchronous processing stages backed by bounded
L<Acme::Parataxis::Channel>s.

Each stage in a stream pipeline is a factory: calling C<map>, C<filter>, C<batch>, C<batch_time>, or C<throttle>
allocates a private bounded output channel, spawns an isolated background fiber to process items, and returns a new
C<Stream> object wrapping that output channel. Calling C<consume> terminates the pipeline and begins draining items.

Key architectural guarantees:

=over

=item *

B<Automatic backpressure>: Output channels between stages are strictly bounded (governed by C<stage_capacity>). If a
stage processes items slower than its upstream feeder, the intermediate channel fills and the upstream fiber parks.
Backpressure propagates naturally all the way to the raw data source without unbounded memory consumption.

=item *

B<Cascading graceful teardown>: Pipelines shut down cleanly from head to tail. When the source channel shuts down, the
first stage reads C<undef> from its input, flushes pending work, and shuts down its output channel. This cascade
propagates downstream, unwinding all intermediate fibers until C<consume> finishes.

=item *

B<Cancellable stages>: Because stages park on standard channels, enclosing C<with_timeout> scopes and cancellation
tokens interrupt in-flight stages cleanly.

=back

=head1 METHODS

=head2 C<from_channel( $channel, [%opts] )>

    my $stream = Acme::Parataxis::Stream->from_channel( $raw_ch, stage_capacity => 64 );

Class method. Wraps an existing L<Acme::Parataxis::Channel> as the head of a new stream pipeline.

=over

=item * C<stage_capacity =E<gt> $int>: The buffer capacity assigned to all intermediate channels allocated by stages in
this pipeline (default C<128>). Must be C<E<gt>= 1>.

=back

=head2 C<map( sub ($item) { ... } )>

    $stream->map( sub ($item) { transform($item) } );

Transforms each item by passing it to the provided callback, emitting the callback's return value downstream.

=head2 C<filter( sub ($item) { ... } )>

    $stream->filter( sub ($item) { $item->{active} } );

Evaluates each item against the callback predicate. Emits the item downstream only if the callback returns true.

=head2 C<batch( $count )>

    $stream->batch(50);

Groups incoming items into arrayrefs of at most C<$count> items before emitting them downstream. If the upstream
channel shuts down mid-batch, any buffered items are emitted as a partial final batch so no data is stranded. C<$count>
must be C<E<gt>= 1>.

=head2 C<batch_time( $ms )>

    $stream->batch_time(500);

Groups items by time deadline. When the first item of a batch arrives, a timer of C<$ms> milliseconds is armed. When
the deadline fires, the accumulated batch is flushed downstream immediately, even if no further items have arrived.
When the source shuts down, pending items are flushed as a final batch.

=head2 C<throttle( $per_second )>

    $stream->throttle(20);    # max 20 items per second

Paces emissions so that no more than C<$per_second> items pass downstream per second. The first item passes
immediately; subsequent items sleep for the remainder of their time window. If backpressure downstream stalls the
throttle stage, it does not "burst" to catch up when unblocked. C<$per_second> must be C<E<gt>= 1>.

=head2 C<consume( sub (@items) { ... } )>

    my $sink_fiber = $stream->consume( sub (@batch_or_item) { ... } );

Terminal consumer stage. Invokes the callback for each item (or unpacked batch) arriving at the end of the pipeline.
Returns the C<Acme::Parataxis> fiber object driving the consumer. Await this fiber to block until the entire pipeline
has drained and terminated.

=head2 C<shutdown( )>

    $stream->shutdown;

Closes the stream stage's source channel and walks upstream, closing preceding channels. Causes the pipeline to drain
and terminate downstream.

=head2 C<cap( )>

Returns the configured C<stage_capacity> shared across intermediate channels in this pipeline.

=head2 C<chain( )>

Returns the immediate upstream C<Acme::Parataxis::Stream> stage, or C<undef> at the head.

=head1 Recipes

=head2 Live event processing with count and time flushing

    async {
        my $events = Acme::Parataxis::Channel->new( capacity => 500 );

        my $sink = Acme::Parataxis::Stream->from_channel( $events, stage_capacity => 64 )
            ->filter( sub ($ev) { $ev->{level} eq 'ERROR' } )
            ->batch_time(2000)    # flush at least every 2 seconds
            ->consume( sub (@errors) {
                ship_alerts(@errors);
            } );

        # Push events...
        $events->shutdown;
        $sink->await;
    };

=head1 Behavior Notes

=over

=item * Arrayrefs from C<map> are unpacked by C<consume>

C<consume> treats incoming arrayrefs as batches and unpacks them into C<@_>. If a C<map> callback legitimately returns
an arrayref meant to represent a single data item, wrap it in a secondary container (e.g. C<[ $my_arrayref ]>) or a
blessed object.

=item * Stage callback exceptions terminate the run

Exceptions thrown inside C<map>, C<filter>, or C<consume> callbacks propagate out of that stage's internal fiber and
will terminate the enclosing scheduler run unless guarded. Trap expected errors inside your callbacks.

=item * Stacking C<batch> stages creates nested arrays

Chaining C<batch_time> directly into C<batch> does not create a union constraint; it batches the batches, producing
nested arrayrefs (e.g. C<[ [1, 2], [3, 4] ]>).

=back
