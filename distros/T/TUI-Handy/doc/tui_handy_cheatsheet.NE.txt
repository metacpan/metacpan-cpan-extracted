======================================================================
 TUI::Handy Cheat Sheet                                  [NE] नेपाली
======================================================================

[ 1. स्थापना र लोडिङ ]

  कुनै CPAN निर्भरता छैन; Handy.pm लाई @INC भित्रको कुनै पनि डाइरेक्टरीमा कपी गर्नुहोस्, वा यसलाई सीधै स्क्रिप्टको रूपमा चलाउनुहोस्।

  use TUI::Handy;
  # or, as a command:  perl Handy.pm form.txt

[ 2. फारम बनाउने र चलाउने ]

  DSL स्ट्रिङ वा फाइलबाट फारम बनाउनुहोस्, त्यसपछि run() कल गर्नुहोस्; नतिजा DSL मा दिइएका लेबलहरूलाई कुञ्जी बनाएको ह्यास रेफरेन्स हो।

  my $tui  = TUI::Handy->new(dsl => $text);   # or new(file => $path)
  my $form = $tui->run;
  print "Company = $form->{Company}\n";

[ 3. टेक्स्ट बक्सका चिन्हहरू ]

  [ ] भित्रका भर्ने अक्षरहरूले टेक्स्ट बक्सको प्रकार छान्छन्: _ आधा-चौडाइ, # संख्या, $ वा \ मुद्रा, YYYYMMDD वा % मिति, र पूरा-चौडाइको कुनै पनि अक्षर zenkaku प्रकारको लागि।

  Company: [__________]
  Age:     [###]
  Price:   [$$$$$$]
  Date:    [YYYYMMDD]

[ 4. चेकबक्स र रेडियो बटन ]

  [X]/[ ] चेकबक्स हो (मान 1 वा 0); (*)/( ) ले अघिल्लो हेडिङ लाइनअनुसार रेडियो बटनहरूलाई समूहबद्ध गर्छ, जसको मान चयन गरिएको लेबल पाठ हो।

  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium

[ 5. बटन ]

  अगाडि लेबल पाठ नभएको वर्गाकार कोष्ठक बटन हो; यसको कार्यलाई set() ले दर्ता गर्नुहोस्।

  $tui->set('Register', sub { my $form = shift; save($form); 0 });
  [Register]

[ 6. कुञ्जीहरू ]

  TAB/तल तीर अर्को फिल्डमा जान्छ, Shift-TAB/माथि तीर अघिल्लो फिल्डमा। Enter, Space र तीर कुञ्जीहरूले फिल्ड सम्पादन गर्छन् वा बटन सक्रिय गर्छन्; ESC ले फारम रद्द गर्छ।

[ 7. क्यारेक्टर इन्कोडिङ ]

  Windows बाहेकका प्रणालीमा UTF-8 र Windows मा Shift_JIS (CP932) स्वतः पहिचान हुन्छ; EUC-JP पनि समर्थित छ। TUI_HANDY_ENCODING बाट अधिलेखन गर्न सकिन्छ।

  $ENV{TUI_HANDY_ENCODING} = 'euc';   # utf8 / sjis / euc

[ 8. लाइन-मोड फलब्याक ]

  stty उपलब्ध नहुँदा (शुद्ध Windows cmd.exe), पोर्टेबल लाइन-मोड ड्राइभर स्वतः प्रयोग हुन्छ; TUI_HANDY_MODE ले मोड जबरजस्ती लगाउनुहोस्।

  $ENV{TUI_HANDY_MODE} = 'line';      # ansi / line

[ 9. कमाण्ड लाइन प्रयोग ]

  कुनै Perl कोड नलेखी DSL फाइललाई सीधै चलाउन सकिन्छ।

  perl Handy.pm form.txt

[ 10. पूर्ण उदाहरण ]

  सबै विजेट प्रकार मिसाएको छोटो DSL उदाहरण।

  Registration
  Company: [__________]
  Age:     [###]
  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium
  [Register]
