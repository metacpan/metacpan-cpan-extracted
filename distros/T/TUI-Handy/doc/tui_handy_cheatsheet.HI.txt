======================================================================
 TUI::Handy Cheat Sheet                                  [HI] हिन्दी
======================================================================

[ 1. इंस्टॉलेशन और लोडिंग ]

  कोई CPAN निर्भरता नहीं है; Handy.pm को @INC के किसी भी डायरेक्टरी में कॉपी करें, या इसे सीधे स्क्रिप्ट के रूप में चलाएँ।

  use TUI::Handy;
  # or, as a command:  perl Handy.pm form.txt

[ 2. फ़ॉर्म बनाना और चलाना ]

  DSL स्ट्रिंग या फ़ाइल से फ़ॉर्म बनाएँ, फिर run() को कॉल करें; परिणाम एक हैश रेफरेंस है जिसकी की DSL में दिए गए लेबल हैं।

  my $tui  = TUI::Handy->new(dsl => $text);   # or new(file => $path)
  my $form = $tui->run;
  print "Company = $form->{Company}\n";

[ 3. टेक्स्ट बॉक्स के चिह्न ]

  [ ] के अंदर भरण अक्षर टेक्स्ट बॉक्स का प्रकार तय करते हैं: _ हाफ-विड्थ, # संख्या, $ या \ मुद्रा, YYYYMMDD या % तिथि, और कोई भी फुल-विड्थ अक्षर zenkaku प्रकार के लिए।

  Company: [__________]
  Age:     [###]
  Price:   [$$$$$$]
  Date:    [YYYYMMDD]

[ 4. चेकबॉक्स और रेडियो बटन ]

  [X]/[ ] एक चेकबॉक्स है (मान 1 या 0); (*)/( ) पिछली हेडिंग पंक्ति के अनुसार रेडियो बटन को समूहित करता है, जिसका मान चयनित लेबल टेक्स्ट होता है।

  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium

[ 5. बटन ]

  बिना लेबल टेक्स्ट वाला वर्गाकार कोष्ठक एक बटन है; इसकी क्रिया को set() से रजिस्टर करें।

  $tui->set('Register', sub { my $form = shift; save($form); 0 });
  [Register]

[ 6. कुंजियाँ ]

  TAB/नीचे तीर अगले फ़ील्ड में जाता है, Shift-TAB/ऊपर तीर पिछले फ़ील्ड में। Enter, Space और तीर कुंजियाँ फ़ील्ड को संपादित करती हैं या बटन को सक्रिय करती हैं; ESC फ़ॉर्म को रद्द करता है।

[ 7. कैरेक्टर एन्कोडिंग ]

  गैर-Windows सिस्टम पर UTF-8 और Windows पर Shift_JIS (CP932) स्वतः पहचाना जाता है; EUC-JP भी समर्थित है। TUI_HANDY_ENCODING से ओवरराइड करें।

  $ENV{TUI_HANDY_ENCODING} = 'euc';   # utf8 / sjis / euc

[ 8. लाइन-मोड फ़ॉलबैक ]

  जब stty उपलब्ध न हो (शुद्ध Windows cmd.exe), स्वतः एक पोर्टेबल लाइन-मोड ड्राइवर उपयोग होता है; TUI_HANDY_MODE से मोड को बाध्य करें।

  $ENV{TUI_HANDY_MODE} = 'line';      # ansi / line

[ 9. कमांड लाइन उपयोग ]

  बिना कोई Perl कोड लिखे किसी DSL फ़ाइल को सीधे चलाया जा सकता है।

  perl Handy.pm form.txt

[ 10. पूरा उदाहरण ]

  सभी विजेट प्रकारों को मिलाकर एक छोटा DSL उदाहरण।

  Registration
  Company: [__________]
  Age:     [###]
  [X] Agree to terms
  Plan
  (*) Basic
  ( ) Premium
  [Register]
