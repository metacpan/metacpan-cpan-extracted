# AGENTS.md

## Build and Test

This project uses **Minilla** with `Module::Build::Tiny` for distribution builds.

- **DO NOT edit Build.PL directly** — it's auto-generated by Minilla. Edit `minil.toml` instead.
- **Setup**: Run `perl Build.PL` to generate the `Build` script.
- **Tests**: Run `./Build test` or `prove t/` directly. Tests use `Test::More` and sample feeds in `t/samples/`.
- **Dependencies**: Declared in `cpanfile`, not `Makefile.PL`. Minilla handles the mapping.

## Code Formatting

Code must follow `.perltidyrc` conventions (enforced by Minilla):

- **80 character line limit**
- **2-space indentation**
- Configured in `.perltidyrc` — do not override per-file

When adding or modifying code, ensure it adheres to these settings. The `.perltidyrc` config has already been applied to the codebase.

## Release and Versioning

Versioning is managed by Minilla:

- **Version bumping**: Edit `lib/Mojo/Feed.pm` (or the main module in `lib/`) and update the `$VERSION` variable.
- **Changelog**: Update `Changes` file with the format: `date release_tag - description`
- **Releases**: Minilla handles packaging; the `META.json` and package metadata are auto-generated.

## Perl Version

Minimum Perl version is **5.10.0** (declared in `cpanfile`). Currently tested on 5.42.1.
