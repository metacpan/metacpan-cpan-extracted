=head1 NAME

Alien::Xrepo::Runtime::Alt - A package-bound view of an Alien::Xrepo::Runtime

=head1 SYNOPSIS

    my $sdl3 = Exotic::SDL3->new;

    # every accessor defaults to the recipe's primary package
    $sdl3->cflags;

    # alt() binds the same accessors to another package in the family
    my $ttf = $sdl3->alt('libsdl3_ttf');
    $ttf->version;
    $ttf->cflags;
    $ttf->libpath;

=head1 DESCRIPTION

C<Alien::Xrepo::Runtime::Alt> is the small adapter L<Alien::Xrepo::Runtime/alt> returns when the requested package is
not the recipe's primary package. It holds a reference to the owning runtime and a single package name, and forwards
every consumer accessor to the owner with that name supplied.

It exists so a multi-package Alien can hand a consumer an object whose accessors all answer for one library. This
mirrors L<Alien::Base>'s C<alt( )> model: an FFI or XS binding written for one library in a family (the SDL3 core, say,
or its C<ttf> extension) can take an object that does not have to be told which package it is for on every call.

The object is a thin view: it stores no state of its own beyond the package name. Calling C<alt( )> on it returns the
C<Alt> for another package (or the base runtime, for the primary), so navigation is uniform. Requesting an unknown
package dies, exactly as it does on the runtime itself.

=head1 CONSTRUCTOR

    my $alt = Alien::Xrepo::Runtime::Alt->new(
        base => $runtime,          # the owning Alien::Xrepo::Runtime
        pkg  => 'libsdl3_ttf'      # the package to bind accessors to
    );

Instances are created for you by L<Alien::Xrepo::Runtime/alt>; there is no reason to construct one directly.

=head1 ATTRIBUTES

=over

=item B<pkg_name>

The single package name this view is bound to. (Compare the runtime's C<package_names( )>, which lists every package in
the recipe.)

=back
